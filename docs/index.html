你挑過的字，關機重開之後還記得。不會每隔一段時間又要把同一個字挑一次。

AI 智慧選字（選配，預設關閉）

整句一起判斷該用哪些字，而不是逐字猜。模型與運算全部在你的電腦上， 不連伺服器。你不主動開啟，它不會下載、也不會連網。

選字記憶存在你自己的電腦裡，權限只有你讀得到，而且不列入 Time Machine 備份。

記憶體不足的機器仍可正常使用輸入法，只是不提供這項功能。

安裝

  1. 打開下載到的 DMG，雙擊「安裝狸注音」。
  2. 到 系統設定 → 鍵盤 → 輸入方式，確認「狸注音」在清單裡。
  3. 用 Ctrl + Space 或右上角的輸入法選單切換到狸注音。

裝完了，但輸入方式清單裡沒有「狸注音」

macOS 有一個我們繞不過去的限制：程式化把輸入法加進清單的系統介面會回報成功、 實際上什麼都沒做，而你自己動手加就加得進去。安裝器偵測到這個情況時會直接告訴你，不會假裝安裝成功。

手動加入：系統設定 → 鍵盤 → 輸入方式 → 按 ＋ → 左邊選「繁體中文」→ 選「狸注音」→ 加入。

雙擊安裝器被系統擋下來

如果這個檔案是從飛書、微信這類 app 直接收到的，macOS 有機會擋掉它， 訊息不一定看得懂（實際遇過的是 File created by an AppSandbox, exec/open not allowed）。 這不是檔案壞了，也不是沒有公證，是 macOS 對「沙盒 app 存下來的檔案」的保護。

先把 DMG 存到「下載」資料夾再打開。還是被擋的話，在終端機執行：

xattr -dr com.apple.quarantine ~/Downloads/LiliBopomofo-*.dmg

然後重新掛載——桌面上舊的掛載卷要先退出，已經掛上的那個不會因為你改了 DMG 就變好。

驗證下載的檔案

輸入法看得到你打的每一個字，所以你有理由確認拿到的是原本那個檔案。 在終端機執行 shasum -a 256，結果應該與下面完全相同：

bbf59e717fa4f72b983d5ca90a7bf98a5b0a5e4c8ba0dd704dc8584737dfc286
